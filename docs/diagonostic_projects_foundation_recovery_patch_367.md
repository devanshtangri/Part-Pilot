## Root cause

Patch 366 invoked copied smoke with:

```text
DATABASE_URL=sqlite:////data/.patch366_smoke_....db
```

Part Pilot's settings model reads:

```text
PARTPILOT_DATABASE_URL
```

The override was therefore ignored and smoke used `/data/partpilot.db`. The suite
restored all values and fixture rows, but its settings restoration advanced three
`app_settings.updated_at` fields. Patch 366 then correctly detected a logical
live-database difference after its documentation commit had already been pushed.
