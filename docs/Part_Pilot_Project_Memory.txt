- Filenames begin directly with the number, never `patch_`.
- Successful scripts print exactly `Everything PASS` as the final line.
- Validate repo, branch, origin, HEAD, source/index state, prerequisites and
  every transformation in memory before backup/write.
- Never assume GitHub represents uncommitted local source.
- Backups: /projects/Part Pilot/fixes/backups/
- Logs/reports: /projects/Part Pilot/fixes/logs/
